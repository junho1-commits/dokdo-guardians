# 독도 수호대

모덕초등학교의 초등학생용 독도 탐험 학습 게임입니다. 산이·나리와 함께 여섯 방에서 사진과 자료를 관찰하고 단서를 연결합니다.

## 실행

Node.js가 설치된 컴퓨터에서 `npm start`를 실행한 뒤 http://127.0.0.1:4173/ 에 접속합니다. Windows에서는 `실행.cmd`를 사용할 수 있습니다.

GitHub Pages에서는 별도 설치 없이 브라우저로 실행할 수 있습니다. WebGL을 지원하는 브라우저가 필요합니다.

## 조작

- WASD·방향키: 이동 / Shift: 달리기
- 좌클릭 드래그·Q/R: 회전 / 마우스 휠: 확대·축소
- 1·2·3: 일인칭·자유 시점·위에서 보기
- CapsLock: 캐릭터 방향 고정
- E: 조사 / B: 가방 / M: 지도 열기·닫기

진행과 학습 기록은 사용 중인 브라우저에 저장됩니다. 학생의 Google 로그인은 필요하지 않습니다.

## 자료 및 권리

실제 사진의 출처와 이용조건은 `assets/photos/출처와이용조건.md` 및 게임 안에 표시되어 있습니다. Three.js 라이선스는 vendor 폴더에 포함되어 있습니다. 학교 교표·캐릭터 및 다른 자료의 권리는 각각의 권리자에게 있으며, 공개 저장소라는 이유로 모든 자료에 동일한 재사용 허가가 부여되는 것은 아닙니다.

게임 지도와 설명용 그림은 학습용 표현으로 실제 독도의 지형·방문 동선을 재현하지 않습니다.

## 확인

`npm test`는 기본 진행과 저장 데이터 검사를 실행합니다. 그래픽·카메라·학습 화면은 별도 브라우저 점검이 필요합니다.
