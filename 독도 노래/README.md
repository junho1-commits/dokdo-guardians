# 🇰🇷 독도는 우리 땅! 신나는 빈칸 노래 퀴즈 웹 앱

초등학교 6학년 사회과 교육과정과 연계하여 학생들이 **〈독도는 우리 땅〉**의 2012년 개정 가사를 신나고 자연스럽게 외울 수 있도록 제작된 인터랙티브 퀴즈 웹 애플리케이션입니다.

---

## 📂 파일 구성
* **`index.html`** : 퀴즈 앱 실행 파일 (더블클릭하면 크롬, 엣지, 웨일 등 웹 브라우저에서 바로 실행됩니다)
* **`dokdo_song_classic.mp3`** : 정광태 원곡자 공식 2012 개정판 음원 (교과서 표준 버전)
* **`dokdo_song_flashmob.mp3`** : 전 국민 독도 플래시몹 신나는 버전 (축제/행사용 빠른 비트)
* **`gangchi.jpg`** : 귀여운 아기 강치 마스코트 이미지
* **`dokdo_island.jpg`** : 독도 바닷속 무지개 일러스트 배경

## ✨ 주요 기능 및 특징

### 1. 🎵 노래가 멈추고 이어지는 자동 재생 시스템
- 노래가 경쾌하게 흘러가다가, **암기해야 할 핵심 빈칸 단어가 나오는 순간 음악이 자동으로 일시정지**됩니다.
- 학생이 정답을 맞히면 **경쾌한 "딩동댕~" 효과음**과 함께 빈칸이 채워지며, **노래가 자동으로 이어집니다.**

### 2. 🎯 수준별 3단계 난이도 지원
1. **🟢 [하] 객관식 (4지선다형)**:
   - 처음 가사를 익히는 학생이나 저학년도 쉽게 참여할 수 있도록 4개의 보기 중 선택
2. **🟡 [중] 초성 힌트 단답형**:
   - 가사의 초성(예: `[ㅂㄱㄸㄹ]`, `[ㅈㅈㅇ]`, `[ㅊㅈㄷ]`) 힌트를 보고 직접 정답 입력
3. **🔴 [상] 단답형 빈칸 채우기**:
   - 힌트 없이 오직 기억력과 가사의 흐름을 바탕으로 직접 정답 타이핑 (완벽 마스터용)

### 3. 📖 구간별 맞춤 학습 모드
- **🌟 전체 완주 모드**: 1절부터 5절까지 전곡을 노래에 맞춰 완주
- **1절 ~ 5절 개별 선택 연습**:
  - **1절 (위치와 자연)**: 87K, 새들의 고향, 우리 땅
  - **2절 (주소와 기후)**: 독도리, 북위 37, 13도, 1800
  - **3절 (생태와 주민)**: 홍합 따개비, 최종덕, 김성도, 19만
  - **4절 (역사적 기록)**: 지증왕, 울진현, 대마도는 조선땅
  - **5절 (영유권과 수호)**: 임자 없는 섬, 이사부, 웃는다

### 4. 💡 6학년 사회과 연계 '교과서 쏙쏙 돋보기' 해설
- 정답을 맞힐 때마다 해당 단어에 얽힌 역사·지리적 배경 설명(예: 세종실록지리지 기록, 최종덕·김성도 주민 이야기, 지증왕 13년 우산국 복속 등)이 나타나 깊이 있는 학습이 가능합니다.

### 5. 🏆 독도 지킴이 명예 임명장 & 축하 폭죽
- 전 문제를 완주하면 축하 팡파레와 색종이 폭죽이 터지며, 학생 이름을 입력하여 인쇄하거나 캡처할 수 있는 **[독도 지킴이 임명장]**이 수여됩니다.

## 🚀 수업 활용 팁
1. **학급 전체 활동 (전자칠판/프로젝터)**:
   - 교실 대형 화면에 `index.html`을 띄우고, 반 전체가 노래를 따라 부르다가 빈칸이 멈추면 다 함께 정답을 외치거나 대표 학생이 나와서 터치하여 풀기.
2. **개별/모둠 학습 (크롬북, 태블릿, 컴퓨터실)**:
   - 학생들이 각자 태블릿이나 PC에서 `[하] → [중] → [상]` 순서로 단계를 높여가며 100점 만점과 콤보 기록에 도전.
3. **오프라인 100% 작동**:
   - 인터넷 연결 없이도 로컬 폴더 안의 음원과 Web Audio 효과음으로 원활하게 작동합니다.
