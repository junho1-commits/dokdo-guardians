# 🏅 58mm 독도의 날 버튼 프레스 원형 도안집 (8종 에디션)

인터넷 조사와 사료·생태 연구를 바탕으로 **10월 25일 독도의 날**을 기념하여 제작한 **58mm 버튼 프레스 전용 순수 2D 원형 도안 8종**입니다.  
3D 목업이나 메탈 프레임 없이, **인쇄하여 바로 오려낼 수 있는 평면 원형 도안**으로 구성되어 있습니다.

## 🖨️ 인쇄 및 제작 방법
1. [`인쇄하기.html`](file:///d:/OneDrive%20-%20%EB%AA%A8%EB%8D%95%EC%B4%88%EB%93%B1%ED%95%99%EA%B5%90/%EC%95%B1%20%EA%B0%9C%EB%B0%9C/%EC%9E%90%EB%A3%8C%EA%B0%9C%EB%B0%9C%20%ED%95%99%EC%8A%B5/%EB%8F%85%EB%8F%84/버튼%20프레스/인쇄하기.html)을 브라우저에서 엽니다.
2. **[🖨️ A4 1:1 실제 크기로 인쇄하기]** 버튼을 클릭합니다.
3. 인쇄 설정에서 **[배율: 100% (실제 크기)]**로 설정하면 A4 용지 2장에 4개씩 총 8개 도안이 정확한 70mm 크기로 출력됩니다.
4. 외곽 빨간 점선(지름 70mm)을 따라 원형 커터기나 가위로 오려내어 58mm 버튼 프레스 기계로 찍으시면 완성됩니다!
